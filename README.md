# news-image-20261118

One image summing up 18 November 2026's world news, drawn by a program.

`main.ts` (Node, stdlib only) renders a 1024×1024 editorial poster: the day's six biggest stories as panels — Gulf strikes, the Crimea bridge falling, the three-leader APEC summit, Democrats taking the Senate, measles returning, Ebola surging — plus a footer ticker with the rest of the day.

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` → writes `out/entry.png`.
